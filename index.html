第1回／全10回

電源を入れる

きょうのめあてパソコンの電源を入れて、最初の画面までたどりつく。
iPhone でいうと横のボタンを押して、パスコードを入れるのと同じです。
  1. 電源ボタンをさがします。丸に縦棒が1本入ったマーク「⏻」が目じるしです。ノートパソコンでは、キーボードの右上あたりにあることが多いです。
  2. 電源ボタンを1回、短く押します。長く押しつづける必要はありません。
  3. 画面が明るくなるまで、1分ほど待ちます。
  4. 時計や写真が大きく出たら、キーボードの Enter（エンター）キーを1回押します。
  5. PIN と書かれた入力らんが出ます。決めてある数字（暗証番号）を、キーボードの数字キーで打ちます。
  6. 画面が切りかわって、下に細い帯のある画面になれば成功です。この画面をデスクトップといいます。
つまずきやすいところ画面が暗いままのときは、充電ケーブルがささっているか見てください。PIN がわからないときは、ご家族に聞きましょう。
きょうはここまででも大丈夫やめたいときは、ノートパソコンならふたを閉じるだけでかまいません。正しい電源の切り方は第3回でおぼえます。

第2回／全10回

マウスに慣れる

きょうのめあてマウスで矢印を動かし、「クリック」と「ダブルクリック」ができる。
iPhone でいうとiPhone は画面を指でさわります。パソコンは画面にさわらず、マウスで矢印を動かして、ボタンを押します。

iPhone の動きと、くらべてみましょう

iPhoneパソコン
1回タップクリック
左ボタンを1回、カチッ
アプリを開くダブルクリック
左ボタンをすばやく2回、カチカチッ
長押し右クリック
右ボタンを1回
指でなぞって送るスクロール
ホイールを回す
押さえたまま動かすドラッグ
左ボタンを押したままマウスを動かす

やってみましょう

  1. マウスを軽くにぎり、机の上ですべらせます。画面の白い矢印（ポインター）がいっしょに動きます。
  2. 机のはしまで来てしまったら、マウスを持ち上げて、まん中に置きなおします。持ち上げているあいだ、矢印は動きません。
  3. 画面の左上にある ごみ箱 の絵に矢印を合わせ、左ボタンを1回押します。色がうすくつきます。これが「選んだ」という合図です。
  4. 何もないところで左ボタンを1回押します。色が消えます。
  5. 何もないところで右ボタンを1回押します。小さなメニューが出ます。何もないところを左クリックすると消えます。
  6. ごみ箱 をダブルクリックします。四角い画面（ウィンドウ）が開きます。
  7. 開いた画面の右上のすみにある × をクリックすると、閉じます。
つまずきやすいところダブルクリックは、2回のあいだにマウスが動くと失敗します。マウスを机に押さえるようにして、指だけを動かしてみてください。
迷ったら「左ボタンを1回」。これが基本です。右ボタンは、使うときにこの教室で言います。
マウスがないとき（タッチパッド）キーボードの手前の四角い板を使います。1本指でなぞると矢印が動き、トンと1回たたくとクリック、2本指でたたくと右クリック、2本指で上下になぞるとスクロールです。

第3回／全10回

画面の名前と、電源の切り方

きょうのめあて画面の場所の名前を知り、正しく電源を切ることができる。
iPhone でいうと「スタート」は、ホーム画面にもどるのに近いものです。困ったら、まずスタートを押す、とおぼえてください。

スタートを開いてみる

  1. タスクバーの スタート（青い窓のマーク）をクリックします。
  2. 大きなメニューが開きます。これがスタートメニューです。
  3. もう一度 スタート をクリックすると閉じます。開く・閉じるを2、3回くり返してみましょう。

電源を切る

  1. スタート をクリックします。
  2. スタートメニューの右下にある 電源 のマーク「⏻」をクリックします。
  3. 小さなメニューが出ます。シャットダウン をクリックします。
  4. しばらくすると画面が消えます。これで終わりです。
メニューのことば意味
シャットダウン電源を完全に切る。1日の終わりに。
スリープひと休み。すぐ続きができる。
再起動切って、すぐ入れなおす。調子が悪いときに。
つまずきやすいところ本体の電源ボタンを長く押して切るのは、やめましょう。かならず画面の「シャットダウン」から切ります。

第4回／全10回

アプリを開く・閉じる

きょうのめあて「メモ帳」を開いて、大きさを変えて、閉じることができる。
iPhone でいうとアプリは iPhone のアプリと同じ意味です。ちがうのは、パソコンではアプリが「ウィンドウ（窓）」という四角い枠の中に開くことです。

メモ帳を開く

  1. スタート をクリックします。
  2. スタートメニューの中の すべて（または すべてのアプリ）をクリックします。アプリの一覧が出ます。
  3. マウスのホイールを手前に回して、一覧を下へ送ります。「め」のところまで進みます。
  4. メモ帳 をクリックします。白い四角い画面が開きます。

ウィンドウの3つのボタン

やってみましょう

  1. ―（最小化）をクリックします。メモ帳が見えなくなります。
  2. タスクバーにメモ帳の小さな絵が残っています。それをクリックすると、もどってきます。
  3. □（最大化）をクリックします。画面いっぱいになります。同じ場所をもう一度クリックして、元にもどします。
  4. ウィンドウのいちばん上の帯に矢印を合わせ、左ボタンを押したままマウスを動かします（ドラッグ）。ウィンドウごと動きます。
  5. ×（閉じる）をクリックして、メモ帳を終わります。
つまずきやすいところ「画面が消えた！」と思ったら、たいていは最小化です。タスクバーを見て、アプリの絵をクリックしてください。

文字を打つ

きょうのめあてキーボードで日本語と数字を打ち、まちがいを直すことができる。
iPhone でいうとiPhone は「あ」を押してから指をはじきます。パソコンは、ローマ字で打ちます。「か」なら K A です。

やってみましょう

  1. 第4回と同じように メモ帳 を開きます。
  2. 白いところを1回クリックします。細い縦の線がチカチカします。ここに文字が入ります。
  3. タスクバーの右のほうを見ます。あ なら日本語、A なら英語です。A のときは 半角/全角 キーを1回押して あ にします。
  4. K A K E I B O と打ちます。「かけいぼ」と出ます。
  5. スペース を1回押します。「家計簿」に変わります。ちがう漢字が出たら、もう一度 スペース を押すと次の候補になります。
  6. Enter を押します。これで文字が決まります。
  7. もう一度 Enter を押すと、次の行にうつります。
  8. わざと何か打って、Back space で消してみましょう。
  9. 数字は、いちばん上の段の 1〜0 で打ちます。「3280」と打って Enter を押します。

ローマ字のおさらい

あAいIうUえEおO
かKAきKIくKUけKEこKO
さSAしSIすSUせSEそSO
たTAちTIつTUてTEとTO
んNNがGAしょSYOきゃKYAってTTE

「ん」は N を2回。小さい「っ」は、次の字のはじめを2回打ちます（きって → KITTE）。

家計簿のことばで練習

打つキー変換すると
SYOKUHI食費
DENNKIDAI電気代
KOUTUUHI交通費
SU-PA-スーパー（のばす音は -）
  1. 練習が終わったら × でメモ帳を閉じます。「保存しますか？」と聞かれたら 保存しない をクリックします。
つまずきやすいところ打っても「kakeibo」と英語のままのときは、半角/全角 キーを1回押してください。これがいちばん多いつまずきです。

Excel をひらく

きょうのめあてExcel を開き、「セル」の場所を名前で言える。
Excel（エクセル）とは方眼紙のノートです。ます目に文字や数字を書くと、計算をかわりにやってくれます。出納帳や成績表をつけるのに向いています。

Excel を開く

  1. タスクバーに、緑色の Excel の絵があれば、それをクリックします。
  2. なければ スタート → すべて とクリックし、「E」のところにある Excel をクリックします。
  3. はじめの画面が出たら 空白のブック をクリックします。ます目がならんだ画面になります。
セルの名前教室の座席表と同じです。「B列の2行目」のます目は B2 とよびます。図の緑のわくが B2 です。

やってみましょう

  1. 好きなセルをクリックします。緑のわくがそこに動きます。
  2. A1、C3、D5 を順にクリックしてみましょう。左上の小さならんに、セルの名前が出ます。
  3. キーボードの矢印キー ↑ ↓ ← → でも、緑のわくが動きます。
  4. このまま第7回へ進んでもよいですし、× で閉じてもかまいません。「保存しますか？」と聞かれたら 保存しない をクリックします。

家計簿に書きこむ

きょうのめあて見出しをつくり、4日分の支出を書きこむ。

できあがりは、このような表です。

ABCD
1日付内容分類金額
211月1日スーパー食費3280
311月2日電気代光熱費6450
411月3日バス交通費420
511月5日本趣味1650

見出しを書く

  1. Excel を開き、空白のブック をクリックします。
  2. セル A1 をクリックします。
  3. 「日付」と打ちます（NIDUKE → スペース で変換）。
  4. Enter を2回押します。1回目で漢字が決まり、2回目でセルに入ります。
  5. 同じように、B1 に「内容」、C1 に「分類」、D1 に「金額」と入れます。セルは、クリックして選びます。

1日分を書く

  1. A2 をクリックし、11/1 と打って Enter。「11月1日」と表示されます。ななめ線 / は、右下の「め」と書かれたキーです。
  2. B2 をクリックし、「スーパー」と入れます。
  3. C2 をクリックし、「食費」と入れます。
  4. D2 をクリックし、「3280」と入れます。円マークやカンマは打たなくてかまいません（第9回でつけます）。
  5. 残りの3行も、上の表を見ながら入れてみましょう。

直したいとき

やりたいことやり方
書きなおすそのセルをクリックして、そのまま新しく打つ。前の中身は置きかわります。
消すそのセルをクリックして Delete（デリート）キー。
ひとつ前にもどすCtrl を押しながら Z。失敗を取り消せます。
つまずきやすいところ打ったのにセルに入らないときは、Enter をもう1回押してください。日本語のときは「決める」と「入れる」で2回いります。
楽をするコツTab（タブ）キーを押すと、右どなりのセルへ進みます。「日付 → Tab → 内容 → Tab → 分類 → Tab → 金額 → Enter」と打つと、マウスにさわらずに1行書けます。
ここでやめるときはせっかく書いた表を消さないよう、先に第10回の「はじめて保存する」をやってから閉じましょう。

合計を出す

きょうのめあて「オート SUM」で、金額の合計を Excel に計算させる。
ここが Excel のいちばん便利なところ電卓はいりません。数字をあとで直せば、合計もひとりでに直ります。
  1. 第7回の表を開いたまま、A6 をクリックして「合計」と入れます。
  2. D6 をクリックします。金額のいちばん下の、すぐ下のセルです。
  3. 上の ホーム タブの、右のほうにある Σ（オート SUM）をクリックします。
  4. D2 から D5 が点線でかこまれ、D6 に =SUM(D2:D5) と出ます。「D2 から D5 までを足す」という意味です。
  5. Enter を押します。D6 に 11800 と出れば成功です。
ABCD
1日付内容分類金額
211月1日スーパー食費3280
311月2日電気代光熱費6450
411月3日バス交通費420
511月5日本趣味1650
6合計11800

たしかめてみましょう

  1. D4 をクリックし、「840」と打って Enter。バス代を倍にしてみます。
  2. 合計が 12220 に変わります。何もしなくても、計算しなおしてくれました。
  3. Ctrl を押しながら Z で、420 にもどしておきましょう。

行を足したいとき

  1. 左はしの行番号 6（合計の行）を右クリックします。
  2. 出てきたメニューの 挿入 をクリックします。合計の上に、空の行がひとつできます。
  3. その行に新しい支出を書きます。
  4. 合計のセルをクリックし、もう一度 オート SUM → Enter。足す範囲が取りなおされます。
つまずきやすいところ点線のかこみが金額の列とちがうところについたら、Esc（エスケープ）キーでやめて、D6 をクリックするところからやりなおしてください。

見やすくととのえる

きょうのめあて見出しを太くし、金額にカンマをつけ、線を引く。

使うのは、どれも ホーム タブのボタンです。ボタンに矢印を合わせてしばらく待つと、名前が小さく出ます。それで確かめられます。

見出しを太字にする

  1. A1 に矢印を合わせ、左ボタンを押したまま D1 まで動かして、はなします（ドラッグ）。4つのセルがまとめて選ばれます。
  2. B（太字）のボタンをクリックします。

金額にカンマをつける

  1. 列の名前 D をクリックします。D列がまるごと選ばれます。
  2. ,（桁区切りスタイル）のボタンをクリックします。3280 が 3,280 になります。

列のはばを直す

  1. 文字がはみ出したり、「####」と出たりしたら、はばが足りない合図です。
  2. 列の名前のさかい目（たとえば B と C のあいだの線）に矢印を合わせます。矢印の形が、左右を向いた形に変わります。
  3. そこでダブルクリックします。中身に合ったはばに、ひとりでに広がります。

線を引く

  1. A1 から D6 までドラッグして、表全体を選びます。
  2. 罫線（田の字のような小さなボタン）の右どなりの ∨ をクリックします。
  3. 出てきた一覧から 格子 をクリックします。

保存する・また開く

きょうのめあて家計簿に名前をつけてしまい、次の日にまた開くことができる。
iPhone でいうとiPhone のメモは、書けばそのまま残ります。パソコンでは、自分で「保存」をして、はじめて残ります。保存したものをファイルとよびます。

はじめて保存する

  1. 左上の ファイル タブをクリックします。
  2. 左にならんだ中から 名前を付けて保存 をクリックします。
  3. 参照 をクリックします。小さなウィンドウが開きます。
  4. そのウィンドウの左がわにある ドキュメント をクリックします。ここが、書類をしまう引き出しです。
  5. 下のほうの ファイル名 のらんをクリックし、入っている文字を消して「家計簿」と打ちます。
  6. 保存 をクリックします。Excel のいちばん上に「家計簿」と出れば成功です。

2回目からの保存

  1. 書きたしたら、Ctrl を押しながら S。これだけです。上書き保存 といいます。
  2. 終わるときは、右上の × で Excel を閉じます。
  3. 「変更を保存しますか？」と聞かれたら 保存 をクリックします。

次の日に、また開く

  1. Excel を開きます。
  2. はじめの画面の 最近使ったアイテム に「家計簿」があります。それをクリックします。
  3. 見つからないときは、タスクバーの黄色いフォルダーの絵（エクスプローラー）をクリック → ドキュメント → 「家計簿」をダブルクリックします。
つまずきやすいところ画面の左上に「自動保存」が「オン」と出ているときは、Excel がひとりでに保存しています。そのときは Ctrl＋S をしなくても大丈夫です。
ここまでできたら卒業ですあとは毎日、1行ずつ書きたすだけ。月がかわったら、同じやり方で新しい表をつくれます。最後に、第3回の シャットダウン で電源を切りましょう。

いつでも見られます

困ったとき

まず深呼吸たいていのことは、Esc キーを押すか、Ctrl を押しながら Z で元にもどります。

打っても英語（ローマ字）のまま

左上の 半角/全角 キーを1回押します。タスクバーの右が あ になれば日本語です。

まちがえて消した、変になった

Ctrl を押しながら Z。ひとつ前にもどります。くり返し押せば、さらに前へもどれます。

知らないメニューや小さな画面が出た

左上の Esc キーを押すか、キャンセル をクリックします。

画面がまっ暗になった

ひと休み（スリープ）しているだけです。マウスを動かすか、キーをひとつ押します。それでもだめなら、電源ボタンを短く1回押します。

開いていた画面が消えた

下にしまわれただけ（最小化）です。タスクバーにあるアプリの絵をクリックします。

矢印（ポインター）が見つからない

マウスを左右に大きくふってみてください。動くものが目に入ります。

文字やます目が急に大きく・小さくなった

Ctrl を押しながらホイールを回すと、大きさが変わります。知らずに回してしまったのでしょう。同じやり方でもどせます。

アルファベットが大文字ばかりになる

Shift を押しながら Caps Lock を1回押します。

セルに「####」と出る

列のはばが足りません。列の名前のさかい目をダブルクリックします（第9回）。

デスクトップ
電源を入れて最初に出る、いちばん広い画面。机の上にあたります。
タスクバー
画面の下の細い帯。スタートや時計がならびます。
スタート
青い窓のマーク。アプリを開く入口で、電源を切るのもここからです。
アプリ
iPhone のアプリと同じ。Excel やメモ帳のこと。
ウィンドウ
アプリが開く四角い枠。「窓」という意味です。
ポインター
マウスで動かす、画面の白い矢印。
カーソル
文字が入る場所でチカチカする、細い縦の線。
クリック
マウスの左ボタンを1回押すこと。iPhone のタップ。
ダブルクリック
左ボタンをすばやく2回押すこと。ものを開くときに使います。
右クリック
右ボタンを1回押すこと。メニューが出ます。iPhone の長押しに近いものです。
ドラッグ
左ボタンを押したままマウスを動かすこと。
スクロール
ホイールを回して、画面を上下に送ること。
ファイル
保存した書類ひとつ。「家計簿」もファイルです。
フォルダー
ファイルをしまう入れもの。「ドキュメント」もフォルダーです。
保存
書いたものをパソコンにしまうこと。保存しないと消えます。
ブック
Excel のファイルのこと。ノート1冊にあたります。
シート
ブックの中の1ページ。
セル
Excel のます目ひとつ。A1、B2 のようによびます。
行・列
行はよこの並び（1、2、3…）、列はたての並び（A、B、C…）。
シャットダウン
電源を完全に切ること。
スリープ
ひと休み。キーを押すとすぐ続きができます。
